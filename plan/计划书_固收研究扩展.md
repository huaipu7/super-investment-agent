## 4. 数据真实性与防泄漏红线（约束 #7，沿用 backtest 经验）

1. **绝不捏造数据**：所有数值来自真实数据源或真实计算；缺失字段显式 `None` / `"—"`。LLM 只做文本，数值必须由代码真实计算。
2. **信用评级真实性**：S&P/Moody's/Fitch 评级是商业数据，免费源拿不到合同级 feed → 用**可合法获取的 proxy**（结构模型连续风险分 / OAS 市场隐含评级），并在报告里**如实标注 label 来源与局限**。
3. **防 look-ahead**：`train <= cutoff < test`，walk-forward 滚动；越界抛 `DataLeakageError`（沿用 backtest_workflow 红线）。
4. **point-in-time**：财务用 EDGAR **实际 filing date**（非报告期）；宏观用 vintage（as_of 前最后一个可得值）；曲线用发布日。
5. **策略来源可追溯**：每条输出带数据源 + as_of + 模型版本，供复核。
